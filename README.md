# AI-Assisted Editorial Pipeline (n8n & Claude)

A scalable production-grade workflow automation that completely overhauled the publishing pipeline for a high-volume digital media platform, scaling efficiency by 90%.

## 🚀 Impact & Results
* **Time Savings:** Slashed average publishing time **from 20 minutes to 2 minutes** per article.
* **Scale Capacity:** Maintained operational velocity that sustained **over 3,000,000 monthly impressions** across web, YouTube, and TikTok channels at peak.
* **Manual Reduction:** Automated 90% of repetitive workflows including topic tagging, basic SEO meta-generation, and formatting.

## 🛠️ Tooling
* **n8n:** Advanced node-based workflow orchestration and API webhooks.
* **Claude (Anthropic):** Structured prompt framework for entity extraction and factual summaries.
* **WordPress:** Automated ingestion and publishing.

## 🔄 Automated Steps Covered
`Source Monitoring` ➔ `Topic Discovery` ➔ `Duplicate Detection` ➔ `AI Quality Ranking` ➔ `SEO Generation` ➔ `WordPress Deployment`
